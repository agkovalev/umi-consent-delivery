# Статус

Локальный пилот v0.1.0 реализован и проверен 2026-09-29 в ветке feature/delivery-mvp.

- Реестр установок, хеши ключей, ротация и отзыв, разрешения на версии.
- Импорт неизменяемого ZIP, проверка SHA-256 и подписанный RSA-3072/SHA-256 манифест.
- PHP 7.3 CLI: проверка подписи и файлов, установка в каталог версии, отдельная активация и локальный откат.
- Docker Compose и CI; образы закреплены по digest.

Проверено: отказ при неверной подписи, повреждённом/неполном файле, redirect, HTTP 503, неверном ключе; сохранение активной версии; ручная активация, локальный откат, отказ server downgrade и параллельного запуска.

Полный сценарий: реальные архивы v0.5.0/v0.6.0 импортированы с проверкой sidecar; PHP 7.3.33 в Docker скачал v0.6.0, проверил подпись Node.js и установил/активировал релиз. Chromium подтвердил UmiConsent.version=0.6.0, локальные JS/CSS одной версии, открытие настроек и отсутствие запросов к delivery API или внешним провайдерам. `pnpm check` проходит; `pnpm audit --audit-level high` не нашёл известных уязвимостей. CI добавлен, удалённый запуск пока не выполнялся.

Пилот доступен на http://localhost:8088; сервис на 127.0.0.1:3100. Ключи, SQLite и релизы находятся в игнорируемой .local; закрытый signing key не смонтирован в контейнеры.

## Интеграция umidev2 — 2026-09-29

Установка umidev2 получила и активировала v0.6.0 через https://umi-consent-delivery.cloudpub.ru с проверкой TLS, подписи и хешей в PHP 8.3.31. Закрытый ключ подписи отсутствует на сайте; ключ установки хранится вне document root. Проверены http://localhost:8081 и https://umi-cookie-consent.cloudpub.ru: локальные JS/CSS одной версии, настройки, сохранение отказа после перезагрузки, отсутствие браузерных запросов к delivery API. Существующий UmiConsentConfig сохранён побайтно; новый HTML появился без очистки кеша.

Первичная проверка выявила запросы к mc.yandex.ru, ulogin.ru и sonar.semantiqo.com из старых социальных виджетов demomarket.lib-min.js. По решению пользователя uLogin и Яндекс «Поделиться» отключены в umidev2: отдельная воспроизводимая сборка исключает оба vendor-блока, патч убирает их интерфейс. Обычная форма входа и регистрация сохранены. На локальном адресе и HTTPS-туннеле `pnpm test:umidev2` подтвердил ноль попыток внешних запросов до согласия, после отказа, принятия и отзыва, без JS-ошибок. Это проверка главной страницы, не полный аудит cookies/магазина. Подробности: docs/UMIDEV2.md.

## Эксплуатация — 2026-09-29

Добавлены команды backup/verify/restore: согласованный снимок WAL, проверка базы, подписей и всех файлов, восстановление только в новый каталог. Реальная копия пилота восстановлена отдельно: 2 релиза, 2 установки. Тесты проверяют сохранение разрешений, ротированных/отозванных ключей, журнала и отказ при повреждениях/перезаписи.

Добавлены лимиты 600 запросов/мин на процесс и 60/мин на установку, Retry-After и тесты сохранения активной версии PHP при 429. Compose ограничивает RAM/CPU/PID и размер журналов. Инструкции и ограничения: docs/OPERATIONS.md.

Обновлённый Docker-пилот запущен и healthy; ограничения подтверждены через Docker inspect. Клиент umidev2 через HTTPS подтвердил доступ к v0.6.0. `pnpm check`, PHP-тесты и браузерный smoke пилота проходят.

Следующий этап: выбрать production-hosting, внешнее хранилище резервных копий, расписание и мониторинг. Туннели остаются тестовой инфраструктурой. Платежи, кабинет, автоматическое обновление и автоматическая ротация signing key остаются вне пилота.
