# Начните здесь

Это клиент доставки umi-cookie-consent для обычного PHP-хостинга.
На клиентском сайте Docker, Node.js и npm не нужны.
Версия ZIP относится к клиенту доставки, а версия скачиваемой библиотеки задаётся оператором отдельно.

1. Получите у оператора адрес HTTPS-сервера, ключ вашей установки и доверенный `public.pem`.
2. Проверьте SHA-256 ZIP по переданному оператором sidecar. Распакуйте вне публичной папки сайта.
3. Переименуйте **копию** `config.example.json` в `config.json`, заполните поля и установите права 0600.
4. Запустите `php doctor.php config.json --online --web-root /абсолютный/путь/public_html`.
5. Выполните `php update.php config.json install`, затем `php update.php config.json activate ВЕРСИЯ`.
6. Только после активации подключите helper и JS/CSS в шаблоне.

Полные шаги с примерами:

- [Интегратору сайта](docs/INTEGRATOR.md) — установка, cron, шаблон, обновления и откат.
- [Оператору сервера](docs/OPERATOR.md) — выдача ключей, разрешения, импорт релизов и администрирование.
- [Эксплуатация](docs/OPERATIONS.md) — резервные копии и ограничения сервера.

В ZIP намеренно отсутствуют ключи, PEM, действующий конфиг и сама библиотека.
Доверенный PEM получите отдельно от оператора; не скачивайте его автоматически из API.
Ключ установки хранится только в приватном config.json и не передаётся браузеру.
Ни один PHP-файл установщика не нужно открывать через браузер.

При ошибке диагностики выполните указанное исправление и повторите команду.
Для обращения к оператору передайте строки OK/WARN/FAIL; не отправляйте config.json,
ключи, скриншот выдачи ключа или содержимое приватного каталога.
