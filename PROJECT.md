# umi-consent-delivery

Канал обновлений umi-cookie-consent для установок, которым оператор выдал доступ.
Первый этап: локальный пилот, ручное управление через CLI, отдельное одобрение версии и ручная активация на сайте.

Сервис написан на Node.js/TypeScript и Fastify, реестр хранится в SQLite. PHP CLI-клиент устанавливает подписанные релизы; браузер получает файлы с самого сайта. Платежи, кабинет клиента и production-развёртывание относятся к следующим этапам.

Репозиторий библиотеки отвечает за сборку и релиз. Репозиторий доставки импортирует готовый проверенный ZIP, не пересобирает библиотеку и не изменяет её конфигурацию согласия.
